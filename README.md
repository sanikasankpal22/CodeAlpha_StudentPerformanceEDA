# CodeAlpha - Student Performance EDA

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project focuses on Exploratory Data Analysis (EDA) of student performance data to identify patterns, trends, relationships, and factors that may influence students' exam performance.

## Objectives

- Understand the structure of the dataset
- Perform data cleaning and preprocessing
- Explore different variables in the dataset
- Identify trends and patterns
- Analyze relationships between variables
- Create meaningful visualizations
- Generate useful insights from the data

## Dataset

The dataset contains information related to student performance and factors such as:

- Hours Studied
- Attendance
- Parental Involvement
- Access to Resources
- Extracurricular Activities
- Sleep Hours
- Previous Scores
- Motivation Level
- Internet Access
- Tutoring
- Family Income
- Teacher Quality
- School Type
- Peer Influence
- Physical Activity
- Learning Disabilities
- Parental Education
- Distance from Home
- Gender
- Exam Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Import required libraries
2. Load the dataset
3. Understand the dataset
4. Check data types and missing values
5. Perform exploratory data analysis
6. Analyze relationships between variables
7. Create data visualizations
8. Identify important patterns and insights
9. Draw conclusions

## Visualizations

The project uses different visualizations to understand the data, including:

- Histograms
- Count plots
- Scatter plots
- Box plots
- Correlation heatmap

## Key Insights

The analysis identifies important patterns and relationships between student-related factors and exam performance.

Detailed observations and visualizations are available in the Jupyter Notebook.

## Project Files

- `StudentPerformance.ipynb` - Complete EDA analysis and visualizations
- `StudentPerformanceFactors.csv` - Dataset used for analysis
- `README.md` - Project documentation

## Conclusion

This project demonstrates the use of Python-based Exploratory Data Analysis techniques to understand student performance data and extract meaningful insights through statistical analysis and visualization.
