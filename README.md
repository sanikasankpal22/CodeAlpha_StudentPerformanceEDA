# CodeAlpha - Student Performance EDA

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project focuses on Exploratory Data Analysis (EDA) of student performance data to identify patterns, trends, relationships, and factors that may influence students' exam performance.

## Objectives

- Understand the structure of the dataset
- Perform data cleaning and preprocessing
- Explore different variables in the dataset
- Identify trends and patterns
- Analyze relationships between variables
- Create meaningful visualizations
- Generate useful insights from the data

## Dataset

The dataset contains information related to student performance and factors such as:

- Hours Studied
- Attendance
- Parental Involvement
- Access to Resources
- Extracurricular Activities
- Sleep Hours
- Previous Scores
- Motivation Level
- Internet Access
- Tutoring
- Family Income
- Teacher Quality
- School Type
- Peer Influence
- Physical Activity
- Learning Disabilities
- Parental Education
- Distance from Home
- Gender
- Exam Score

## Key Insights

Based on the correlation analysis:

- Attendance has the strongest positive relationship with Exam Score (correlation = 0.58).
- Hours Studied also shows a moderate positive relationship with Exam Score (correlation = 0.45).
- Previous Scores have a weak positive relationship with Exam Score (correlation = 0.18).
- Tutoring Sessions show a weak positive relationship with Exam Score (correlation = 0.16).
- Physical Activity has a very weak relationship with Exam Score (correlation = 0.028).
- Sleep Hours show almost no linear relationship with Exam Score (correlation = -0.017).

These correlations describe relationships in the dataset and do not by themselves establish cause-and-effect relationships.
